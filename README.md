\# Terminal Velocity



A first-person data center technician sim — find the failure, then fix it. Real hands-on repair and a real typed terminal, no menus.



\## Status

Early development. Git repo set up, Unity project scaffolded, full design doc in progress.



\## Built with

\- Unity 6 (URP)

\- C#



\## About

You're a technician who splits time between a command center and the server room floor: catch an alert, track down the failing rack, diagnose it, and fix it — sometimes by hand, sometimes through the terminal, often both.
